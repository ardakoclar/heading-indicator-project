# heading-indicator-project
Web-based Aircraft heading indicator simulator project of team "Karadeniz Bombası"

# Heading Indicator Simulator

Bu proje, **Elektronik Gösterge Sistemleri** dersi kapsamında geliştirilmiş bir **Heading Indicator Simulator** uygulamasıdır.  
Uygulama web tabanlıdır ve temel amaç, uçaklarda kullanılan heading indicator göstergesinin çalışma mantığını etkileşimli olarak simüle etmektir.

## Proje Amacı

Bu projede klasik bir heading indicator yapısı dijital ortama aktarılmıştır.  
Kullanıcı heading değerini değiştirebilmekte, göstergenin gerçek zamanlı hareketini gözlemleyebilmekte ve ek olarak bazı yardımcı özellikleri kullanabilmektedir.

## Özellikler

Projede aşağıdaki temel özellikler bulunmaktadır:

- Gerçek zamanlı heading animasyonu
- Slider ile kullanıcı girişi yaparak heading değiştirme
- Gerçek enstrümana benzer görsel tasarım
- Green Mode (alternatif gösterge teması)
- Önceden tanımlı uçuş senaryosunun otomatik oynatılması
- Enstrüman arızası simülasyonu (failure mode)

## Kullanılan Teknolojiler

- HTML
- CSS
- JavaScript
- GitHub Pages

## Proje Dosya Yapısı

- `index.html` → sayfanın ana yapısı
- `style.css` → tasarım ve görsel düzen
- `script.js` → heading hesaplama, animasyon ve buton fonksiyonları

## Nasıl Çalıştırılır?

Projeyi lokal olarak çalıştırmak için:

1. Dosyaları bilgisayarınıza indirin veya repoyu klonlayın.
2. `index.html` dosyasını tarayıcıda açın.
3. Slider ve butonlar üzerinden sistemi test edin.

## Kullanım

- Slider ile heading değeri değiştirilebilir.
- **Green Mode** butonu ile alternatif tema açılıp kapatılabilir.
- **Start Demo Flight** ile otomatik heading senaryosu çalıştırılabilir.
- **Trigger Failure** ile arıza modu simüle edilebilir.
- **Recover Instrument** ile sistem normal duruma döndürülebilir.

## Ders Kapsamı

Bu proje, **Elektronik Gösterge Sistemleri** dersi için hazırlanmıştır.  
Amaç, uçak göstergelerinin temel mantığını yazılım ortamında sade ama işlevsel şekilde modellemektir.


## Not

Bu proje eğitim amaçlı geliştirilmiştir.  
Gerçek aviyonik sistemlerin tüm fonksiyonlarını içermez, ancak heading indicator mantığını temel seviyede simüle etmektedir.
